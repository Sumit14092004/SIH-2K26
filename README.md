# SIH 2026: Environmental Intelligence Network

## Team Folders
- `hardware_node/`: C++ code for the ESP32 edge nodes. (Recommended to use PlatformIO).
- `backend/`: Code for the MQTT broker, database, and API.
- `dashboard/`: Code for the frontend web application and geospatial mapping.
- `.agents/`: Shared Antigravity rules and configurations for the team.

## Getting Started
1. Clone this repository.
2. Open the project in Antigravity IDE.
3. Coordinate with your team on which folder you are working on.
